Необходимо реализовать на Python следующую функциональность:

- На вход подан датасет который состоит из первых абзацев русскоязычных статей из википедии про различных людей и предствален в виде Python articles : list[str]
- Необходимо создать базу данных из первых 100 текстов в articles. Вам предлагается использовать ChromaDB из langchain. Имя коллекции `collection_name` оставляйте в значении по умолчанию. В качестве модели эмбеддингов используйте `intfloat/multilingual-e5-large` из huggingface.
- Cохраните базу данных на диск с названием `chroma_db`. Никак не обрабатывайте тексты дополнительно.
- подготовить также файл requirements.txt с нужными модулями
